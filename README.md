# 户型装修设计

中文 | [English](README.en.md)

纯前端的户型装修设计工具：在 2D 平面图上绘制户型、摆放家具、拆改墙体、测量尺寸，一键切换到 Three.js 3D 场景，可以鸟瞰，也可以第一人称漫游。整个应用就是一个 `index.html`，无需构建，打开即用。

## 功能

**2D 平面布置**
- “编辑户型”模式中可画墙、房间、门、窗和飘窗；画墙时右侧实时显示长度和厚度，画完自动选中，可输入精确尺寸
- 在 3D 鸟瞰中点击墙体，可在右侧修改该段墙的高度（100–6000 mm）；旧方案墙高自动沿用默认值
- 已画的门、窗和推拉门可从中心拖动位置、拖边线或控制点改尺寸，右侧可输入精确开口宽度与洞口厚度；门可切换合页侧、开门方向并设置 3D 门高，窗可设置窗台高度和窗高
- 相邻同窗台、同窗高的窗段可合成窗组，包括转角 L 形窗；合并时会微调邻近端点，整组移动或删除，也可拆分。选中墙体可合并同类型、同厚度和同高度的近似同线墙段，小间隙会自动补齐
- 飘窗使用凸出的 U 形双线平面图例和三面玻璃 3D 构件，可修改开口宽度、凸出深度、方向、窗台高度及窗高；窗洞仍会切开对应墙体
- 智能吸附适用于门、窗、推拉门的绘制、移动和改尺寸：自动贴合墙体中心线与墙厚，靠近墙端时对齐端点；房间顶点和整边拖动也可对齐墙边，吸附时沿用蓝色参考线和音效
- 洞口可自动切开拐角和交叉墙；移动、缩放或删除洞口时会修复旧位置的墙体
- 已有墙体可从中间拖动；房间可从内部移动、拖动顶点或整条边线调整轮廓，也可输入开间和进深
- 按原始户型 1:60 / 1:100 比例显示，尺寸单位 mm
- 从左侧家具库拖入 60 余种家具家电（卧室、客厅、餐厨、卫浴、家电、书房休闲）
- 拖动移动、旋转（Shift 自由角度）、调整尺寸；开启「智能吸附」后家具可贴墙
- 智能吸附锁定新目标或用 Tab 切换候选时播放短促提示音；顶部「吸附音效」按钮可静音，设置保存在当前浏览器，无需额外音频文件
- 测量工具（靠近墙面自动吸附，Shift 锁定水平 / 垂直）
- 拆改非承重墙，承重墙单独标示
- 图层开关：尺寸标注、房间名、家具、网格、承重墙

**3D 场景**
- 鸟瞰、斜视、俯视多种视角，点击房间列表可飞到对应房间
- 漫游模式：桌面端 WASD + 鼠标，触屏设备用虚拟摇杆，可以点门开关
- 全高墙 / 剖切墙切换，日照时间滑块，夜景灯光
- 精细家具模型：柜门分缝与拉手、软包床头、带环境反射的金属与陶瓷材质等
- 在 3D 中也能选中、拖动家具，与 2D 方案实时同步

**方案与统计**
- 房间面积与套内使用面积自动统计
- 为每个房间更换地面材料（木地板、地砖、大理石、水磨石、地毯等），按面积加 5% 损耗估算造价
- 撤销 / 重做，方案自动保存在浏览器本地
- 中文 / English 界面切换（顶栏右侧按钮，默认中文，选择会记住）
- 导出 PNG 图片，导出 / 导入方案 JSON

## 快速开始

```bash
git clone <仓库地址>
cd <仓库目录>
```

然后直接用浏览器打开 `index.html`。也可以起一个本地静态服务器：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

> Three.js 通过 jsDelivr CDN 加载，首次打开 3D 场景需要联网。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `T` | 切换 2D / 3D |
| `M` / `L` / `PL` | 户型选择与拖动墙体 / 画墙 / 画房间轮廓 |
| `F3` | 开关智能吸附（墙体绘制与拖动、家具贴墙） |
| `Tab` / `Shift + Tab` | 画墙或拖动墙体时切换吸附候选 / 反向切换；输入框中保留正常跳转 |
| 按住 `Space` | 临时拖动画布，松开后继续使用原工具 |
| `DR` / `WI` / `BW` / `SL` | 画平开门 / 窗 / 飘窗 / 推拉门（应用自定义命令） |
| `DI` / `DE` | 测距 / 拆改非承重墙（`DE` 为应用自定义命令） |
| `E` / `Delete` / `Backspace` | 删除所选墙、房间、门窗或家具 |
| `CO` / `RO` | 复制 / 旋转所选家具（`RO` 按住 Shift 反向旋转） |
| `V` | 退出户型绘图，切换到家具选择 |
| `Enter` | 在画房间时完成多边形 |
| `Ctrl/⌘ + D` | 复制选中家具 |
| `Ctrl/⌘ + Z`，`Ctrl/⌘ + Shift + Z` | 撤销，重做 |
| `ZE` / `F` | 适应窗口 |
| `+` / `-` | 放大 / 缩小 |
| `[` / `]` | 展开 / 收起左侧家具库、右侧面板 |
| `Shift + F` | 全屏 |
| `Esc` | 取消当前操作；在户型编辑中返回选择工具 |
| 漫游：`WASD` / 方向键，`Shift`，`E` | 移动，快走，开关门 |

双字母命令连续输入（例如先按 `P` 再按 `L`），无需按回车；输入中会显示蓝色命令提示。常用字母参照 AutoCAD 命令别名，门窗与拆改命令是本应用专用。

## 技术栈

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤
- 2D 平面图用 SVG 绘制
- 3D 场景用 [Three.js](https://threejs.org/) r160（OrbitControls、PointerLockControls、RoundedBoxGeometry、RoomEnvironment、CSS2DRenderer）
- 数据保存在 `localStorage`

## 自定义户型

在 2D 页面点击“编辑户型”，右侧选择绘图工具：

1. 先用“清空户型，重新绘制”建立空白方案；此操作可撤销。已有方案最好先在“文件”菜单导出 JSON 备份。
2. 选择“画墙”，设置墙体类型和厚度，按住鼠标拖出水平或垂直墙段。开启「智能吸附」后，可对齐已有墙体的边缘、端点和墙厚中心线，即使两段墙之间有间隔也能沿延长线对齐；吸附时显示蓝色参考线。普通隔墙、外墙、承重墙和矮墙使用不同显示样式。
   拖动时右侧同步显示长度与厚度；松开后该墙自动选中，可在右侧输入长度和墙厚。修改长度保留起点，修改墙厚保留中心线。
   切换到 3D 鸟瞰后，点击墙体或保持刚才的选择，可在右侧输入墙高。全高墙视图显示实际高度；剖切墙视图会截断显示。
3. 选择“画房间”，逐个点击房间内轮廓的顶点，按 `Enter` 或双击完成。顶点靠近墙边或中心线时可智能吸附。房间会自动命名为“新房间”；在右侧修改名称、开间、进深和地面材料。拖动蓝色边线控制点可移动整条房间边线，并对齐墙边。墙体和房间多边形是独立图形，需要按量房尺寸分别绘制。
4. 选择门、窗、飘窗或推拉门工具，在墙段附近拖出洞口；开启智能吸附后会自动采用墙体方向、中心线和墙厚，并在靠近墙端时对齐端点。拐角和交叉墙也会按洞口区域自动切开。画完自动选中，右侧可输入开口宽度和洞口厚度；平开门可切换合页侧与开门方向，窗可设置窗台高度和窗高，飘窗可设置凸出深度、方向、窗台高度和窗高。选中门后进入 3D 可输入门高；在 3D 中点击门或窗也会显示相应设置。拖动门窗中心可直接吸附到另一面墙；按 `Alt` 拖动可暂时自由移动。拖边线或蓝色控制点调整尺寸时也会智能对齐；移动、缩放或删除时会补回旧洞口。吸附时的蓝色参考线和音效可由 `F3` 与顶部「吸附音效」开关控制，拖动中按 `Tab` 切换候选。
5. 选中相接的窗段，点击右侧“合并相邻窗”；相同窗台高度和窗高的邻近端点会连接，L 形和多段转角窗可作为一组移动、删除，宽度仍按当前窗段编辑。“拆分窗组”可恢复独立编辑。选中墙体后点击“合并同线相邻墙”，会将同厚、同类型、同高度的近似同线墙段对齐到所选墙：端点间隙最多 200 mm、横向偏差最多 20 mm。合并不会跨门窗洞口；右侧会提示可合并段数或无法合并的原因。
6. 直接拖动已有墙体中部或房间内部即可移动，无需先切到“选择 / 拖动”；房间在绘图工具中从中心附近拖动。选中墙后，拖动边线或边中点方块只调整该边，长和墙厚互不干扰；拖动角点时按起始拖动方向锁定单轴。控制点随画布缩小，墙体拖动按 1 mm 取整；开启「智能吸附」时，移动与改边都能沿其他墙的边缘或中心线对齐。关闭后仅保留 1 mm 取整。也可拖动房间顶点改变轮廓。若要在已有图形上开始新绘制，按住 `Shift`；画门窗时按住 `Alt` 可拖动墙体。按 `Delete` 删除所选图形。滚轮缩放，空白处拖动平移；任何 2D 工具下都可按住空格临时平移。

新户型与家具一起保存在当前浏览器的 `localStorage` 中，也包含在“导出方案 JSON”里；GitHub Pages 只托管程序文件，不会保存访客的方案。旧版导出的家具方案仍可导入，并会使用内置户型。

若要修改网站首次打开时的默认户型，可编辑 `index.html` 中的默认数据：

户型数据写在 `index.html` 里：

- `ROOMS`：房间多边形、名称、默认地面材料
- `WALLS` / `WINS` / `BAYS`：墙体、窗洞与飘窗
- `MATS`：地面材料名称与单价
- `LIB`：家具库（类型、名称、默认尺寸、颜色）
- `buildFurniture()`：各类家具的 3D 模型

改这些数据也能换成自己的默认户型。
